# Jira & Confluence Flow

全局 Antigravity 插件，聚合本地 `jira-flow` 与 `confluence-flow` 的全部 Skill 和 MCP 服务。

## 包含能力

- **Jira Skills（9 个）**：`jira-query`、`jira-analyze`、`jira-create`（Story 默认 / 禁止 Task 定制版）、`jira-implement-story`、`jira-fix-bug`、`jira-update-progress`、`jira-export`、`jira-weekly-report`、`jira-personal-report`
- **Confluence Skills（3 个）**：`confluence-query`、`confluence-publish`、`confluence-update`
- **MCP Servers**：`jira_flow`、`confluence_flow`（复用本机 `~/.jira-flow` 与 `~/.confluence-flow` 运行层与 DPAPI 凭证）
