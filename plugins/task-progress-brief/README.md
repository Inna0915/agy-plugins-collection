# Warm Progress & On-Demand UI（原 Task Progress Brief v2.1）

告别机械冰冷的“逐工具调用刷屏日志”，让 AGY 在全局会话中像坐你旁边的资深结对搭档一样：**琐碎动作静默不打扰、关键发现有温度地开口同步、默认用原生 Markdown 极速输出（仅在明确指定时按需渲染内嵌交互微视图）**，并与 `agy-tps-monitor` 右侧「实况伴侣 · TPS 监控」侧边栏形成左右协同工作台。

## 三位一体协同体验

1. **方案一 · 结对搭档式里程碑叙事（左栏对话流）**：
   - 短程（连续 `2～7` 步内）读文件、检索代码、等后台任务完成时保持静默，由 AGY 原生折叠状态条承载，严禁连刷 `正在读取...` / `正在等待...` 机械流水账。
   - 按**「5 个黄金节点 + 8 步保活封顶」**自然沟通：**开场定路线、动手改码/写大补丁前必报方案（利用同一步 `content` 先于工具流式渲染，零额外轮次即可随时纠偏）、抓到关键发现/阶段跃迁、连续静默满 `~8` 步阶段保活、遇到脏改动招呼或分叉决策（`ask_question`）**。
2. **方案四 · 聊天内嵌交互微视图（Generative UI `<agent-embed>`，严格按需触发）**：
   - 默认不生成 `.html` 微视图，优先用紧凑的 Markdown 表格/列表保证响应速度；仅当你在指令中明确要求“用交互卡片/微视图展示”时，才按需生成深浅色自适应 HTML 卡片内嵌在对话中。
3. **方案三 · 右侧「实况伴侣 · TPS 监控」面板（Sidecar 侧边栏）**：
   - 即使在静默探索期间，右侧面板也会实时滚动展示**本轮目标、脑内思考摘要、当前操作文件/命令芯片**，并提供**一键快捷插话/方向纠偏栏**随时向当前会话发送调整指令。

## 管理与开关

- **图形界面**：在 Customizations（技能与自定义）面板中找到 **Warm Progress & Generative UI**（目录 `task-progress-brief`）即可一键启用或停用，实时生效无需重启。
- **命令行（`agy` CLI）**：
  - 查看状态：`agy plugin list`
  - 临时停用：`agy plugin disable task-progress-brief`
  - 重新启用：`agy plugin enable task-progress-brief`
